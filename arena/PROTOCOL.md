# Agent Arcade Cup: fixed protocol

- Source snapshot: local checkout of `NnopponS/100-games`, Daylight release `96857ba2d7d3fde6a3cc51e5e34ec808bb920165`. Raw source-file hashes are emitted with the results.
- Pool fixed before the scored run: 2048 Classic (#09), Sliding Puzzle Arcade+ (#31; adjacent slides), Lights Out Classic (#32), Battleship Classic (#34). All have discrete legal actions and inspectable outcomes. Not a random sample of all 100 games; randomly scheduled from these four eligible titles without changing the pool.
- 100 independently drawn **round seeds** and a seeded randomized order of a balanced deck (25 of each title), starting from `0x4b4e5431` (“KNT1”). Execution order randomized independently by round. Seeds are not provided to the contestants.
- Two actual independent subagents write separate deterministic contestant JavaScript programs from the same public interface. Bots, not live LLM clicking, play 200 independent native games. The comparison is paired: both contestants get the same seeded initial game, including opponent fleets in Battleship. 2048 samples the same random stream, but different boards can map a draw to different empty tiles. Actions are discrete, simultaneous competitive equivalence is an experimental design, not native head-to-head multiplayer.
- The JavaScript inside the original game HTML is executed in a seeded Node VM with a minimal DOM shim, virtualized gameplay timeouts, no project data imports and no soundtrack or score effects. Four small adapters route legal actions through the original game functions and read public board state. Renderer does not adjudicate the match.
- Caps and lexicographic ranking (higher each vector component wins): **2048** 88 moves, native score then largest tile; **Sliding** 120 moves, completion then fewer moves, otherwise lower remaining Manhattan distance excluding blank; **Lights** 25 presses, completion then fewer moves, otherwise fewer lit cells; **Battleship** 80 shots, enemy ships sunk, native hits, then fewer shots. No wall-clock performance tiebreaker; ties stay ties. Illegal, timed-out and other bot-fault rounds are explicit losses unless both fault (tie). Unexpected game-adapter faults stop the run rather than silently advancing.
- Contestant actions are synchronous, limited to 250 ms per action via VM; fresh contestant VM per round; no browser or Node APIs beyond the language/state/action interface. No network or I/O by bots. Neither source can inspect the opposing bot or engine state.
- A moves archive, seed manifest, source hashes and verification results travel with the output. Any visualization is explicitly labeled as recorded replay, not pretense of live human input or browser playback. Timings in edits are editorial time compression; they are not experiment measurements.
