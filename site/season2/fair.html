Which deadline is usable?

Historical sweep: replaying the 83 completed Kev replies from the 1,500 ms matches with shorter cutoffs. This does not resimulate the match; new moves can change the next game state. The decision is checked at the next 100 ms polling tick and can still be rejected if the game position changed.

DeadlineReturned by tickStill valid in game

1,200 ms is the starting budget for this CPU setup. It preserved all 83 completed replies in the historical sweep, versus 79 at 1,100 ms. The live pair tests it with no game pauses. It is a practical timing setting, not a substitute for lockstep when ranking tactic selection. A cap is not a win.

In lockstep, the game advances 24 frames per decision (400 ms of game time) and does not advance while replies are pending. Engine-queued actions can still differ because fighters can be busy, hit or unable to act. These matches qualify the format; they are not tournament rounds.
